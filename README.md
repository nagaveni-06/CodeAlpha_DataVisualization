# CodeAlpha - Task 3: Data Visualization

## Project Title
Data Visualization using the Iris Dataset

## Project Description
This project was completed as part of the CodeAlpha Data Analytics Internship. The objective is to transform raw data into meaningful visualizations using Python. Various charts and graphs were created to better understand the distribution, relationships, and characteristics of the Iris dataset.

## Objective
- To visualize the Iris dataset using Python.
- To create different types of graphs for better data understanding.
- To identify patterns, relationships, and distributions through visualizations.
- To improve data interpretation using graphical representation.

## Tools and Technologies Used
- Python
- Visual Studio Code (VS Code)
- Pandas
- Matplotlib
- Seaborn

## Dataset
- Dataset Name: Iris Dataset
- File Format: CSV
- File Name: `iris.csv`

## Visualizations Created
- Histogram
- Box Plot
- Scatter Plot
- Heatmap
- Bar Chart

## Project Outcome
The visualizations helped in understanding the distribution of features, identifying outliers, examining relationships between variables, and comparing the number of samples in each Iris species. The project demonstrates how graphical representations make data easier to analyze and interpret.
